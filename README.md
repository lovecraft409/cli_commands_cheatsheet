I kept forgetting commands I'd used before — I'd remember part of it, like "zshrc" or "grep", but not the full syntax. Every time this happened I'd have to stop what I was doing and go dig through a browser or ask an AI, which killed my momentum.

So I built a small desktop tool with Python and Tkinter. It reads a plain text file of commands I've saved, and as I type, it filters the list live — type a fragment, see matches instantly, click to copy. No bloated feature list, no hundreds of commands I'll never use — just my own notes, searchable in seconds.

It's simple on purpose. I looked at existing cheatsheet tools first, but they came with way more than I needed. Building my own meant I only had exactly what I use, and I understand every part of how it works.
